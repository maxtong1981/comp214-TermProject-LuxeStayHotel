## How to keep the plan current

1. Agree on an owner and reviewer before starting a task.
2. Update the task tracker when work starts, becomes blocked, or is ready for review.
3. Attach the actual deliverable and evidence before marking a requirement verified.
4. Record completed contributions after review.

Use this Markdown tracker initially. If the team moves tasks to GitHub Issues or a board, replace the task table with a link to that board so that only one task tracker remains active.
